A single-line safety warning label that should come printed on every human being — funny first, plausible second. A tiny Python program writes the label to `entry.txt`:

> WARNING: This human has read none of the instructions, understood all of them, and will now explain them to you.

## Run it

```sh
python3 main.py
```

It writes the label (112 characters, one line, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output` by default), validates it against the gate — one line, 1–160 characters, not only whitespace — and verifies the written file is byte-identical.
